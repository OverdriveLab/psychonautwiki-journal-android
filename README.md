# PsychonautWiki Journal

PsychonautWiki Journal 是一款旨在保障娱乐性药物使用者安全的安卓应用。其目标是提供既能吸引用户又能从减少危害的角度出发切实有效的功能。
此应用采用 [Jetpack Compose](https://developer.android.com/jetpack/compose) 原生构建。  
这是一个开源分支，在原项目关闭后仍继续进行开发。
